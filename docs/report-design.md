# 面向业务与产品的评估报告设计

设计日期：2026-10-12。此文档与 `report-preview.html` 为导出报告的设计依据。现有 HTML 导出接口已接入 `evaluator/report_html.py`，样稿保留用于对照，正式报告由批次数据自动生成。

## 读者与阅读顺序

业务读者需要判断回答是否可以使用、哪些数值需要纠正；产品读者需要定位问题类型、影响范围和复测事项。报告可离线打开，不依赖系统登录、后端接口或网络资源。

报告顺序：总体结论 → 评估范围与结果统计 → 七维诊断 → 问题清单 → 每题证据 → 建议与口径说明。业务结论与差异默认展开，完整回答和基准表以可展开证据展示。SQL、模型版本、运行信息放在技术附录，原始 JSON 使用已有 JSON 导出入口，不放在业务报告正文。

## 数据来源与口径

- 最终题目结论：`case_judgment`，沿用持久化 LLM 结果与人工调整优先规则。展示中文标签，人工结论与自动结论并列说明，原始差异不被人工结论覆盖。
- 七维诊断和差异：`llm_evaluation.evaluation.dimensions/differences`。不得回退到历史 `comparison_items` 并称为当前评估。
- 数据证据：`agent_answer.text` 和原评分 `sql_snapshot`，后续 SQL 补查单独标注时间与用途，不混入原评分基准。
- 批次指标：导出时重新调用 `run_evaluation_metrics`，避免使用旧 summary。计划题数来自运行契约快照；已记录题数、未记录题数分开展示。
- 核心“回答合格率”：最终合格题数 / 可评估题数，与当前页面 accuracy 的含义一致。不能称为单元格数值准确率。
- “回答完成率”：已返回回答题数 / 计划题数，来自当前 `final.pass_rate`。不得标为“题目通过率”。
- “可评估率”：可评估题数 / 已记录题数，与现有口径一致。待执行题单列，不混作无法评估。零分母显示“暂无可评估样本”。
- 维度一致率：MATCH / (MATCH + PARTIAL + MISMATCH)，UNKNOWN 与 NA 不进入分母。展示样本数，不能用七维均值代替总体质量。
- 问题分布按受影响题数统计，同题同类型只计一次；差异数量按记录数统计，不与题数混用。
- 差值只对完成标准化的 WRONG_VALUE 计算：标准化回答值 − 标准化基准值；差异率 = 差值 / |标准化基准值|。基准为零、未标准化、非有限数显示“—”，不自行猜测单位。

## 内容规范

首页标题使用“智能体评估报告”，摘要给出范围内的结论，不由单次单题结果推断产品整体可用性或上线结论。总览标注样本数量与评估时间，业务查询期间与评估时间分开。

各题展示：题号、完整问题、业务场景、最终结论、评估摘要、七维检查、异常明细、回答与基准、复核备注。数值统一千分位、右对齐；单位来自契约，字段别名按契约映射；时间与位置不能作为普通数值格式化。

摘要与明细的范围有冲突时明确说明：本样本摘要称三个指标、五个月均有差异，但保存的明细只有六条。报告可以写“记录 6 条差异，涉及 5 个月与 3 个指标”，不可写“15 项错误已逐项核验”。

事实、推测与建议有不同标签。问题原因只能来自可验证证据；未证实根因写“待核验”。不自动生成责任人、修复期限或承诺。人工调整、SQL 错误、基准截断、数据水位变化、缺少评估等会影响判断的状态需出现在正文相关结论旁。

## 多题批次

首页增加题目结论分布与场景统计，默认先展示不合格与部分作答，再显示无法评估、合格。结果清单保留全部题目，支持中文关键词搜索、结论筛选与题号锚点；筛选明确只作用于题目清单，首页批次指标不随清单筛选变化。合格题保留证据入口。

问题清单字段：题号、业务问题、结论、主要问题、差异条数、查看详情。严重程度沿用现有 ERROR / 复核信息，不虚构 P0/P1 业务优先级。失败模式可做规则聚合，但不能把异常共现当成根因。

## 版式与交互

白底、深绿色强调色，错误用深红标签，复核用琥珀色，颜色与文字同时传递状态。正文 15px、表格 13–14px、标题 28–36px；间距 8/12/16/24/32px。正文限宽 1160px，七维使用 4+3 栅格，小屏幕两列或一列；表格容器局部横向滚动，文字原因完整换行。

单文件内嵌 CSS 和必要脚本，无 CDN。支持目录锚点、展开全部证据、收起证据、打印/另存 PDF。即使禁用 JavaScript，摘要、正文、原生 details 与表格仍可读。按钮支持键盘操作和焦点可见。

打印隐藏交互控件，展开证据，避免卡片中途断页，表头跨页重复；横向长表按纸张宽度重新排版。打印输出始终标明批次、样本范围与指标公式。

## 落地边界与验收

复用现有 HTML 导出接口，业务报告取代原 HTML 模板；Excel 与 JSON 导出保持为独立格式。报告模板和数据整理函数应拆出 exporter，避免大量模板字符串与数据计算混杂。

验收覆盖：单题失败、多题混合结论、全合格、无评估、未完成批次、人工调整、零分母、负基准、缺少标准化值、基准截断、补查、HTML 转义；总览与逐题数量一致，报告无网络依赖；桌面/手机/打印均无截断，源文件与业务正文均不暴露会话 token、cookie 或原始请求参数。
