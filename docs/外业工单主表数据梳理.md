### 1.3 同名部门的处理方式

**情况一：二级部门与三级部门同名**

`坪地供水公司` 和 `莲塘水司` 既是二级部门也是三级部门。因为这两个单位较小，没有下属水务所，三级部门字段可能为空。脚本将二级部门名称直接填充到三级部门：

```python
df_processed.loc[df_processed.二级部门名称 == '坪地供水公司', '三级部门名称'] = '坪地供水公司'
df_processed.loc[df_processed.二级部门名称 == '莲塘水司', '三级部门名称'] = '莲塘水司'
```

**情况二：新旧名称并存**

部门名称发生过变更（如"xx水司"→"xx水务所"），坐标配置表中同时保留新旧名称，映射到相同坐标以兼容历史数据。典型如：
- 福永水司 / 福永水务所
- 沙井水司 / 沙井水务所
- 松岗水司 / 松岗水务所（已更名为松岗水务运营中心）
- 石岩水司 / 石岩水务所
- 大鹏水务所 / 大鹏水司、南澳水务所 / 南澳水司 等

脚本中的名称替换：

```python
df_department_coordinates['三级部门'] = df_department_coordinates['三级部门'].replace('松岗水务所', '松岗水务运营中心')
```

**情况三：不同二级部门下的同名三级部门**

`管网部` 同时出现在罗湖分公司和福田分公司下。脚本通过**二级部门+三级部门双字段联合匹配**消歧：

```python
df_processed = pd.merge(df_processed,
                       df_department_coordinates[['二级部门', '三级部门', '三级部门坐标', '区']],
                       left_on=['二级部门名称', '三级部门名称'],
                       right_on=['二级部门', '三级部门'],
                       how='left')
```

### 2.2 工单类型名称清洗逻辑

```python
# 1. 去掉"旧"字前缀（如"旧供水管道维修"→"供水管道维修"）
df_processed.工单类型 = df_processed.工单类型.str.replace('旧', '', regex=False)

# 2. 统一新旧名称
df_processed.工单类型 = df_processed.工单类型.str.replace('阀门维修(100以上)', '阀门维修（100以上）', regex=False)  # 半角→全角括号
df_processed.工单类型 = df_processed.工单类型.str.replace('阀门维修工单', '阀门维修', regex=False)              # 去掉"工单"后缀
df_processed.工单类型 = df_processed.工单类型.str.replace('网格小区排水', '网格小区排水工单', regex=False)        # 加上"工单"后缀
```

## 三、工单期间口径（本测评集）

- 工单期间一律 `create_time` 半开区间：`create_time >= :start AND create_time < :end`（GD-001~GD-011）。
- 完成判定用 `finish_time IS NOT NULL`。
- 组织口径按 `bz_bm`（坪地/莲塘按台账映射）。
